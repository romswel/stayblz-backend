# Stayblz email templates

Branded templates for Supabase Auth emails, in the Stayblz glass look. Generated by
`node scripts/build-email-templates.cjs`. Edit the script, not the HTML files, then rebuild. The script refuses to
build if a template shows a code, uses Supabase's `{{ .ConfirmationURL }}`, or loses its `/auth/confirm` link.

## Files to paste (Supabase → Authentication → Emails → Templates)

| Supabase template | Subject (paste from) | Message body (paste from) |
| --- | --- | --- |
| Confirm signup | `confirm-signup.subject.txt` | `confirm-signup.html` |
| Reset password | `reset-password.subject.txt` | `reset-password.html` |
| Invite user | `invite.subject.txt` | `invite.html` |
| Change email address | `change-email.subject.txt` | `change-email.html` |

- **Every email is link-only** (since 2026-11-19; the 6-digit codes are gone). One button opens
  `https://stayblz-app.com/auth/confirm?token_hash=…&type=…`. That page sends the token with its script, so a mail
  scanner that only fetches the link can't use it up. Never switch to `{{ .ConfirmationURL }}`: it confirms on a plain visit.
- The sign-up email also has **"This wasn't me"** (`/auth/not-me`). It can't sign anyone in: it opens a page that asks
  before removing an unverified sign-up made with that address.
- Under each button the same link is printed as text, for mail apps that break buttons.
- `confirm-signup.txt` and `reset-password.txt` are plain-text versions (for reference; Supabase's editor takes HTML).
- **Paste these before releasing the link-only sign-up.** The app no longer has a box for codes, so an email that
  only shows a code can't be used.

## Supabase settings these templates rely on

1. **Authentication → URL Configuration**
   - Site URL: `https://stayblz-app.com` (no `www`). Every link in these emails is built from it.
   - Redirect URLs: `https://stayblz-app.com/auth/confirm`, `https://stayblz-app.com/auth/confirm?recovery=1`,
     and for local testing `http://localhost:5173/auth/confirm`. Remove `https://stayblz-frontend.vercel.app/**`.
2. **Authentication → Providers → Email**
   - Confirm email: **on**.
   - Email OTP Expiration: **3600** seconds (links use it too). The emails say "expires in 1 hour"; if you change
     this, change `LINK_LIFETIME` in the script and rebuild.
3. **Authentication → Emails → SMTP Settings** (Resend)
   - Sender email: an address on the verified domain, for example `no-reply@stayblz-app.com`.
   - Sender name: `Stayblz`.
   - Host `smtp.resend.com`, port 465 (or 587), username `resend`, password = a Resend API key
     with sending access only. Never put the key in this repository.
4. Send yourself a test sign-up and a password reset. Check the button opens Stayblz and verifies, the sender shows
   as Stayblz, and the message isn't in spam.
