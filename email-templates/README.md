# Stayblz email templates

Branded templates for Supabase Auth emails. Generated by `node scripts/build-email-templates.cjs`.
Edit the script, not the HTML files, then rebuild.

## Install (Supabase dashboard)

1. **Authentication → URL Configuration**: Site URL must be `https://stayblz-frontend.vercel.app`
   (the links use `{{ .SiteURL }}`). Keep `/auth/confirm` and `/auth/not-me` under that site.
2. **Authentication → Emails → SMTP Settings**: connect a real email sender (Resend, Brevo, Postmark…).
   Supabase's built-in sender is only for testing: it allows very few emails per hour and may refuse
   to send to people outside your project team, and template editing may be locked without it.
3. **Authentication → Emails → Templates**: for each template, paste the subject from
   [subjects.md](subjects.md) and the matching HTML file:

| Supabase template | File |
| --- | --- |
| Confirm signup | `confirm-signup.html` |
| Reset password | `reset-password.html` |
| Invite user | `invite.html` |
| Change email address | `change-email.html` |

4. Send yourself a test sign-up and a password reset to check the result.

## What each email gives people

- **Sign-up:** a 6-digit code (typed on the sign-up screen), a button, and **"This wasn't me"**,
  which removes an unconfirmed sign-up made with their address (`/auth/not-me`).
- **Password reset:** a 6-digit code (typed on the "Forgot password" screen) and a button.
- The buttons use `token_hash` links handled by `/auth/confirm`, so nothing secret sits in the URL fragment.
